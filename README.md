# ohlcv-mmap

OHLCV mmap-shaped store — stub bars as jobs.

## Features

- Algorithm tag sha256
- Stub job + nonce scan
- No GPU/CUDA runtime required

## Prerequisites

- Rust 1.75+
- Git

## Getting Started

```bash
git clone <repo-url>
cd ohlcv-mmap
cargo build --release
./target/release/ohlcv-mmap --help
```

## Tests

```bash
cargo test
```
